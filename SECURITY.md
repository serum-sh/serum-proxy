# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Report it privately with GitHub: open the [Security tab](https://github.com/serum-sh/serum-proxy/security) and click "Report a vulnerability". You can also use the [direct link](https://github.com/serum-sh/serum-proxy/security/advisories/new).

Include:

- The version or the commit.
- The steps to reproduce the problem.
- The effect, for example the data or the backend that an attacker can reach.
